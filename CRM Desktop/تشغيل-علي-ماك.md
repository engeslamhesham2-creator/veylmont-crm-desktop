# 🍎 تشغيل Veylmont CRM على الماك — خطوة بخطوة

ده الملف بيشرحلك إزاي تشغّل تطبيق الـ CRM على جهاز Mac.
عندك **طريقتين**: تشغيل مباشر (الأسرع للتجربة)، أو بناء ملف **`.dmg`** تثبّته زي أي برنامج ماك.

> ⚠️ مهم: ملفات الماك (`.dmg`/`.app`) **لازم تتبني على جهاز Mac** — مينفعش تتبني من ويندوز.
> فالخطوات دي بتتعمل على الماك نفسه.

---

## 🧰 المتطلبات (مرة واحدة بس)

1. **Node.js** — نزّله من: https://nodejs.org (اختار نسخة **LTS**).
   بعد التثبيت اتأكد إنه اشتغل — افتح **Terminal** واكتب:
   ```bash
   node -v
   ```
   لازم يطلعلك رقم نسخة (مثلاً `v20.x.x`).

2. فك ضغط الملف ده (`Veylmont-CRM-Mac.zip`) في أي مكان — مثلاً على الـ **Desktop**.

---

## ⚡ الطريقة 1: تشغيل مباشر (الأسرع — للتجربة)

1. افتح **Terminal**.
2. ادخل على مجلد المشروع (غيّر المسار لو حطيته مكان تاني):
   ```bash
   cd ~/Desktop/"Veylmont CRM Mac"
   ```
3. ثبّت الحزم (مرة واحدة بس، محتاج إنترنت):
   ```bash
   npm install
   ```
4. شغّل التطبيق:
   ```bash
   npm start
   ```
   ✅ هيظهرلك الـ splash الذهبي ويفتح الـ CRM على طول.

---

## 📦 الطريقة 2: بناء ملف تثبيت (`.dmg`) — زي أي برنامج ماك

1. افتح **Terminal** وادخل على المجلد:
   ```bash
   cd ~/Desktop/"Veylmont CRM Mac"
   npm install
   ```
2. ابنِ ملف التثبيت:
   ```bash
   npm run dist:mac
   ```
3. هتلاقي الملف جاهز في مجلد **`dist/`** باسم زي:
   ```
   Veylmont CRM-1.0.0.dmg
   ```
4. افتح الـ `.dmg` واسحب أيقونة **Veylmont CRM** لمجلد **Applications**.
   خلاص — التطبيق اتثبّت ويفتح من Launchpad زي أي برنامج.

---

## 🔓 أول مرة تفتحه: رسالة "unidentified developer"

التطبيق مش موقّع بشهادة Apple مدفوعة، فأول مرة الماك ممكن يقول:
> "Veylmont CRM" can't be opened because it is from an unidentified developer.

ده طبيعي. الحل (مرة واحدة بس):

**الطريقة أ —** كليك يمين على أيقونة التطبيق → **Open** → في الرسالة اضغط **Open** تاني.

**الطريقة ب —** من **System Settings › Privacy & Security** → انزل تحت لجملة عن "Veylmont CRM" → اضغط **Open Anyway**.

بعد كده هيفتح عادي على طول كل مرة.

## 💡 معلومات مهمة

- التطبيق بيفتح **نفس الموقع الحي** (`keelmont.com`) + **نفس الداتابيز** → أي حاجة تعملها هنا تظهر على الويب والعكس.
- لو قفلت النافذة، التطبيق بيفضل شغّال في **شريط القوائم العلوي** (الإشعارات والصوت بيوصلوك). للخروج نهائي: من القائمة العلوية **Veylmont CRM › Quit**.
- لو النت فصل، هتظهر شاشة "تعذّر الاتصال" بزر إعادة محاولة.

---

## 🔄 (اختياري) بناء تلقائي من GitHub — من غير جهاز ماك

لو معندكش ماك دلوقتي، تقدر تبني نسخة الماك من **GitHub Actions**:
1. ارفع مجلد المشروع على repo في GitHub.
2. شغّل الـ workflow اسمه **"Build & release desktop apps"** (موجود جاهز في `.github/workflows`).
3. هيطلعلك ملف الـ `.dmg` جاهز للتحميل من نتيجة التشغيل (Artifacts).
